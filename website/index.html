BUILD ON WHAT IS THERE
A runtime with clear boundaries.
What the platform provides
Sequential missions, agent routing, capacity limits, whole-mission deadlines, cooperative cancellation, optional verification, atomic progress checkpoints, searchable run history, mission validation, and an HTTP JSON agent.
Remote agents use a token-authenticated JSON-RPC/WebSocket contract. “Sentinel” is the protocol name for an agent.
What your agents provide
Tools, model calls, planning, domain logic, and enforcement of business constraints. Starlight does not interpret arbitrary goals on their behalf.
Agents are trusted code. File storage preserves progress across process exits; an unfinished step may already have caused an effect. There is no automatic replay or rollback.
